# 🛠️ Sistema de Abertura de Chamados

Este projeto é um sistema simples e funcional para abertura de chamados de suporte técnico ou atendimento interno. O formulário permite que os usuários registrem problemas, escolham a categoria e prioridade, e anexem arquivos relacionados.

## ✅ Funcionalidades

- Cadastro de chamados com título e descrição
- Seleção de categoria e prioridade
- Upload de arquivos
- Interface amigável e responsiva
- Validação básica de formulário
